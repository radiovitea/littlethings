# littlethings

Мелкие скрипты, твики и программки, которые упрощают жизнь с Линуксом. Многое здесь сделано под KDE Plasma, но не все.


## Твики

- [overview-wait](docs/overview-wait.md) — «Обзор» (который Meta + W) в KDE открывается с первого нажатия сразу после переключения рабочих столов.


## Плазмоиды

- [browser-switch](docs/browser-switch.md) — небольшой виджет для Плазмы, позволяющий быстро выбирать браузер по умолчанию. По работе иногда нужно использовать другой браузер. Чтобы не мучиться с копированием ссылок, сделал вот такую небольшую штуковину. Добавляется на панель или рабочий стол, по клику выдает список всех установленных браузеров. Также список можно прокручивать колесиком.
